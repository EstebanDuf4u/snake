
Ce projet est une réinterprétation du célèbre jeu Snake, développé en Python avec Brython, directement exécuté dans le navigateur.

L’idée de base était simple : “et si on faisait un Snake en Python… mais version web ?”
Résultat : un jeu 100% côté client où Python remplace le JavaScript pour gérer toute la logique du serpent, des collisions et du score.

Ce projet permet d’explorer :

l’exécution de Python dans un environnement web
la manipulation du DOM via Brython
la logique temps réel d’un jeu classique

Un petit projet fun, entre nostalgie et expérimentation, pour transformer un Snake classique en Snake version Python mdrr 🐍
